# UI 重构与 7z 支持技术笔记 (UI & 7z Notes)

## 一、UI / UX 重构决策

### 1. 搜索优先原则
- **问题**：原界面左侧固定占据 300px 文件树，中间堆叠双层 Card 和多行表单，导致搜索输入框狭窄、首屏视觉噪音大。
- **重构**：
  - 将主搜索条置于全宽视觉中心，使用大尺寸输入框，提供 `Aa`（大小写敏感）、`.*`（正则表达式）和 `筛选`（高级 glob 与最大数）的一键胶囊切换。
  - 文件结构树改为**可折叠侧边栏**，默认收起，打开目录后可通过顶栏快速展开浏览，主体空间几乎 100% 留给检索结果。
  - 顶栏精简为：品牌标识 + 目录胶囊选择器 + 次要操作按钮。支持快捷键 `Ctrl/Cmd+F` 快速聚焦搜索框，Enter 直接触发搜索。

### 2. 结果展示与虚拟列表
- **问题**：原实现使用 Ant Design List 每条匹配单独渲染一个 Antd Card，面对几百上千条日志时产生海量 DOM 节点，引起严重的滚动掉帧与卡顿。
- **重构**：
  - 引入 `@tanstack/react-virtual` 动态高度虚拟列表（`useVirtualizer` + `measureElement`），只渲染可视视口内的节点，万级匹配结果依然流畅。
  - **按文件自动分组**：将匹配块按文件路径聚合，提供可折叠的 Sticky 文件头，展示该文件总命中数，并支持「全部折叠/全部展开」。
  - **紧凑代码行视图**：移除多层嵌套的 Card 边框与阴影，采用专业代码浏览风格，左侧 58px 固定宽行号，匹配行温和底色，关键字精准黄色高亮，上下文行适当弱化。
  - **结果内二次过滤**：提供前端快速过滤输入框，无需后端重新遍历磁盘即可即时按路径或关键词筛选当前展示块。

## 二、7z 支持实现与选型

### 1. Crate 选型
- 选择 `sevenz-rust = "0.6"`：纯 Rust 实现（Pure Rust），无需 C 动态库依赖，具备良好的跨平台兼容性（Linux / macOS / Windows），Apache-2.0 协议符合 MIT 开源要求。
- 仅支持**未加密归档**；若遇到加密归档会优雅返回错误，不进行虚假声明。

### 2. 格式识别与限额贯通
- **文件头魔数识别**：`37 7A BC AF 27 1C`（前 6 字节）。在 `archive::detect_archive_type` 中检测，不依赖 `.7z` 后缀。
- **严格解压保护**：
  - 单条目上限：`MAX_ARCHIVE_ENTRY_SIZE` = 20 MB，超过则跳过该条目。
  - 累计解压上限：`MAX_ARCHIVE_TOTAL_SIZE` = 100 MB，达到后停止后续条目解压，防止 Zip/7z Bomb 导致 OOM。
  - 仅抽取文本类后缀（复用 `is_text_file`）。
- **全链路贯通**：
  - `archive::extract_7z_content`：解压匹配文本文件。
  - `file_ops::search_in_archive`：在 7z 内流式搜索并合并上下文。
  - `file_ops::read_archive_entry_lines`：按内部相对路径安全读取指定条目。
  - `lib::get_archive_contents`：列出 7z 内文本文件列表。
  - `lib::get_file_info` / `read_file_content`：完整支持虚拟路径（如 `app.7z → error.log`）。
