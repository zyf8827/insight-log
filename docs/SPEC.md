# 规格说明 (Specification)

本文档记录 `insight-log` 核心规格要点，作为架构与功能的参考。

## 1. 核心定位
基于 Tauri 2.0 + React 19 + Rust 的轻量级本地日志检索桌面应用，支持普通文本及压缩包（ZIP / TAR / GZ / 7z）内日志的检索与浏览。

## 2. 核心功能规格
- **界面交互与视觉**：
  - 搜索优先：主搜索条处于首屏视觉中心，支持 Enter 触发搜索与快速清空；快捷键 `Ctrl/Cmd+F` 快速聚焦。
  - 高级筛选面板：包含/排除 glob 模式及最大结果数折叠收纳，保持主界面清爽高密度。
  - 文件结构树：改为可折叠侧边栏，打开目录后按需展开浏览，默认将全部空间留给检索结果。
  - 虚拟列表（`@tanstack/react-virtual`）：海量匹配日志按需渲染可视区域，滚动顺畅无卡顿。
  - 按文件分组展示：以文件路径为 sticky 小标题，展示命中块数与行数统计，支持按文件整组折叠与展开。
  - 紧凑代码视图：固定宽度行号列，匹配行背景温和着色，匹配关键字精准 `<mark>` 高亮，弱化非匹配上下文。
  - 摘要与二次过滤：展示匹配文件数、匹配块数、命中行数、耗时毫秒及最大结果数截断警示；支持结果内二次即时过滤。
- **搜索语法**：
  - 管道链式多条件匹配：`pattern1 | pattern2 | pattern3`（同一行内必须同时满足所有条件，即逻辑 AND）。
  - 支持字面量搜索（默认对特殊字符转义）与正则表达式搜索（勾选开关后直接使用 Rust regex 语法）。
  - 支持大小写敏感开关。
  - 支持 glob 模式的文件包含与排除（如 `**/*.log`, `!*.tmp`）。
- **支持的压缩格式**：
  - ZIP (`.zip`) - 魔数 `50 4B`
  - TAR (`.tar`) - 魔数 `75 73 74 61 72` (offset 0x101)
  - GZ (`.gz`, `.tar.gz`) - 魔数 `1F 8B`
  - 7z (`.7z`) - 魔数 `37 7A BC AF 27 1C`（基于 pure-Rust `sevenz-rust` 实现，仅限未加密归档）
  - 基于文件头魔数识别，而非单纯依赖文件后缀。
  - 限额保护：单条目解压上限 20MB，压缩包累计解压上限 100MB，防止 Zip Bomb 与内存溢出。
  - 明确不支持 RAR，亦不支持加密压缩包。
- **安全沙箱**：
  - 所有文件查看与访问严格限制在用户当前选定的搜索根目录范围内，禁止目录穿越。
  - 配置标准 CSP 策略，防止本地 Webview 恶意脚本注入。
- **结果呈现与查看器**：
  - 上下文展示（默认前后各 10 行）。
  - 重叠上下文自动合并为一个连续块，并保持原始行号与高亮。
  - 内置行级查看器（`FileViewer`）与全量文件浏览器（`FileViewerFull`），支持归档内子条目按需读取与跳行定位。
